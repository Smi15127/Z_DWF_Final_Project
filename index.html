Exercise Goals Tracker

James Smith

WDD 131-1

Overview

Purpose

This website is for my exclusive use to track and manage my personal fitness progress and workout regimens.

Audience

My audience is myself. It will store my workouts and track my progress in an organized way.

Dynamic elements

Javascript will be used to store workout regimens in arrays and objects, display them on the calendar, and allow editing and assigning workouts to specific days.

Content

Home page

The home page will include an overview of my fitness goals, quick links to add or view workouts, and recent progress summaries.

Workout Regimens Page

This page will display a list of predefined workout routines (e.g., "Leg Day," "Push/Pull"). Each workout can be edited (number of reps, sets, duration) and assigned to specific calendar days.

Progress Calendar Page

A visual calendar where I can select a day, view assigned workouts, and record performance. Javascript will allow clicking a day to bring it forward, editing notes, or applying workouts.
